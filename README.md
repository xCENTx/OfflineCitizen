An experimental project for limited offline exploration of Star Citizen.

You are responsible for building, configuring, and testing it on your own system. There is no warranty of functionality, stability, compatibility, or fitness for a particular purpose. Use it at your own risk.

## Build and use

See [BUILD.md](BUILD.md) for requirements and local launcher configuration. Use the **x64** configuration. Game structures and offsets are version-specific; a successful build does not guarantee compatibility with your installed game version.

No game files, game assets, personal launch arguments, or account credentials are included. Supply your own local configuration and keep personal settings out of any public upload.
