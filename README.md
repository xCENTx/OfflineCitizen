# OfflineCitizen

**OfflineCitizen** is a community-made mod that enables limited offline exploration of the **Star Citizen Persistent Universe**.  

⚠️ **Important:** This project is **not affiliated with, endorsed by, or supported by Cloud Imperium Games (CIG)**. Star Citizen and all related assets are the property of Cloud Imperium Games and/or their licensors.  

This repository serves as a public hub for information, updates, and binary releases of the mod.  

---

## 📥 Download
Compiled binaries will be available under the [Releases](./releases) section.  
> Note: Source code for the memory interaction logic is **private** and will not be shared.  

---

## 🚀 Features
- Load into the Persistent Universe in **offline mode**.  
- Explore locations without requiring online servers.  
- Lightweight: no modification of game files or redistribution of assets.
